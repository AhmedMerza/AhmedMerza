## About Me

I'm a Full-Stack Software Engineer with 3+ years of experience shipping end-to-end web and mobile products. I specialize in **Laravel** and **Vue.js**, with a strong focus on clean architecture, efficient databases, and cost-effective deployments.

I enjoy owning features from idea to production — whether that's designing a schema, building an API, wiring up a frontend, or deploying to Linux servers.
